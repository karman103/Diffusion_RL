# RL fine-tuning of diffusion models, on one laptop

Controlled experiments on what reinforcement learning, mainly **GRPO**, does to diffusion models:
a video model, RFdiffusion3 for protein backbones, a CIFAR-10 image DDPM and an MNIST DDPM.
Everything runs on a 16 GB Apple M3 MacBook. Every result is measured on fresh seeds and scored by
an evaluator that the training reward never saw.

**Blog:** [RL for diffusion models: what works, and what gets hacked](https://karman103.github.io/Diffusion_RL/)
(source in [`docs/`](docs), served by GitHub Pages). Part 1 compares RL algorithms on MNIST; Part 2 runs GRPO on video, RFdiffusion3 and CIFAR-10.

## Results at a glance

| Study | Model | What GRPO / RL did | Folder |
|---|---|---|---|
| Digit-conditioned video | 1.7M-param space-time UNet, trained from scratch | **+32.4 points** success (49.1% → 81.5%, 95% CI +27.7 to +37.3, 3 seeds); every digit improved; matches best-of-4 at 1× cost | [`image_video_grpo/learned_video/digit`](image_video_grpo/learned_video/digit) |
| Direction-only video (first version) | same | +11.7 points, but by drawing far more 8s (a reward shortcut) | [`image_video_grpo/learned_video`](image_video_grpo/learned_video) |
| Proteins | RFdiffusion3 (168M, frozen) + low-rank adapter | No measurable change across 9 runs and two action designs | [`rfd3_grpo`](rfd3_grpo), [`rfd3_grpo/fix`](rfd3_grpo/fix) |
| Protein inpainting benchmark | RFdiffusion3, crambin gap fill | No measurable change | [`rfd3_flow_benchmark`](rfd3_flow_benchmark) |
| Images | Google CIFAR-10 DDPM | Training reward +0.056, independent classifier +0.009 (reward hacking) | [`image_video_grpo`](image_video_grpo) |
| Text-to-video | ZeroScope, frozen U-Net + output residual | Feasibility pilot only: one update fits in 16 GB | [`text_video_grpo`](text_video_grpo) |
| MNIST reward hacking | 1.5M-param MNIST DDPM | DDPO stays honest under a weak proxy; DRaFT hacks it (0.7% real 7s) | [`mnist_rl`](mnist_rl) |
| Genie POC | Genie protein-backbone checkpoint | Early protein extension | [`protein_poc`](protein_poc) |

## Layout

```
docs/                 GitHub Pages site (the blog post + figures)
rldiff/               shared library: DDIM-as-MDP sampler, models, rewards (used by several studies)
mnist_rl/             MNIST DDPM study: DDPO / RWR / DRaFT / best-of-N vs a weak proxy reward
image_video_grpo/     CIFAR-10 DDPM GRPO, plus the learned video model
  learned_video/      video diffusion model trained from scratch, first GRPO study
    digit/            digit-conditioned model and GRPO (the main video result)
rfd3_grpo/            GRPO on RFdiffusion3 (fix/ = all-atom-action follow-up)
rfd3_flow_benchmark/  RFdiffusion3 crambin / protein G / ubiquitin benchmark
text_video_grpo/      ZeroScope text-to-video GRPO pilot
protein_poc/          Genie protein-backbone RL proof of concept
```

Each study folder has its own README or RESULTS file, a `PROTOCOL.json` written before training
(with amendments recorded), the analysis scripts, and per-sample metrics. Logs are in each study's `logs/`.

## Setup

There are three Python environments, because RFdiffusion3 and the video stack pin different
library versions:

| Environment | Used by | Create |
|---|---|---|
| `.venv` | `mnist_rl`, `rldiff`, `protein_poc` | see [`mnist_rl/README.md`](mnist_rl/README.md) |
| `image_video_grpo/.venv` | `image_video_grpo`, `text_video_grpo` | `uv venv image_video_grpo/.venv -p 3.12 && uv pip install -p image_video_grpo/.venv -r image_video_grpo/requirements.txt` |
| `.venv-rfd3` | `rfd3_grpo`, `rfd3_flow_benchmark` | see [`rfd3_grpo/README.md`](rfd3_grpo/README.md) |

Not committed, so fetch these yourself:

- **Datasets.** MNIST and CIFAR-10 download through torchvision into `data/`.
- **Model weights and checkpoints** (`*.pt`, `checkpoints/`). Pretrained ones download from their
  official sources; trained ones are regenerated by each study's scripts.
- **`third_party/`.** [`fnachon/foundry`](https://github.com/fnachon/foundry) at commit
  `7a9c246fbf140a743d14a35248f5039e7723a23a` (Apple-MPS RFdiffusion3 fork) and
  [`aqlaboratory/genie`](https://github.com/aqlaboratory/genie).
- **`image_video_grpo/vendor/`.** Source from
  [`kuterd/toy_video_dit` @ d5c2ae0](https://github.com/kuterd/toy_video_dit/tree/d5c2ae0dee8ccd90fe50d8cffbcb0ef4b4126f8a).
  It has no declared license, so it is not redistributed here.

## Publishing the blog

In the GitHub repository settings, open **Pages**, set the source to **Deploy from a branch**, and choose
branch `main` with folder `/docs`. The site is plain HTML and CSS (`docs/.nojekyll` turns Jekyll off), so it
needs no build step.
